CachedSqlQueryRow

#

Выполняет кешированный SQL-запрос одной строки и помещает колонки результата в глобальные Lua-переменные.

Luaerr, code = CachedSqlQueryRow(sq, ...)
Важно: каждый ? в SQL должен иметь соответствующее значение после SQL-строки. Не склеивайте значения вручную в SQL.
Входящие параметры
#ПараметрТипОписание
1sqstringSQL-текст запроса
2…...varargsЗначения для SQL-плейсхолдеров `?` в порядке появления. Количество значений должно соответствовать числу `?`. Таблица разворачивается в несколько параметров; nil передаётся как SQL NULL.
Результирующие параметры
#ПараметрТипОписание
1errstringПусто при успехе; колонки результата устанавливаются как глобальные Lua-переменные.
2codeinteger0 — успех; 2 — нет данных; 3 — больше одной строки; другие — ошибка.

Примеры

Пример 1
local err, code = CachedSqlQueryRow(
  "select name, code from dict where id = ?",
  10
)
if code == 0 then print(name, code) else print(err) end
Пример 2
local err, code = CachedSqlQueryRow(
  "select title from roles where code = ? and active = ?",
  "ADMIN", 1
)
if code == 0 then print(title) end

Открывает SELECT во внешней БД и возвращает функцию-курсор для чтения порциями по 100 строк.

LuanextChunk, err, code = SqlQueryRowsExtDbCursor(extDbCode, query, ...)
Важно: каждый ? в SQL должен иметь соответствующее значение после SQL-строки. Не склеивайте значения вручную в SQL.
Входящие параметры
#ПараметрТипОписание
1extDbCodestringКод настроенного подключения внешней БД.
2querystringSQL-текст запроса
3…...varargsЗначения для SQL-плейсхолдеров `?` в порядке появления. Количество значений должно соответствовать числу `?`. Таблица разворачивается в несколько параметров; nil передаётся как SQL NULL.
Результирующие параметры
#ПараметрТипОписание
1nextChunkfunction|nilФункция курсора; каждый вызов возвращает chunk, err, code. Порция — до 100 строк.
2errstringОшибка открытия курсора.
3codeinteger0 при успехе.

Примеры

Пример 1
local nextChunk, err, code = SqlQueryRowsExtDbCursor(
  "erp",
  "select id, name from customers where active = ?",
  1
)
if code ~= 0 then print(err) else
  while true do
    local chunk, chunkErr, chunkCode = nextChunk()
    if chunkCode ~= 0 then print(chunkErr); break end
    if chunk == nil or #chunk == 0 then break end
    for _, row in ipairs(chunk) do print(row.id, row.name) end
  end
end
Пример 2
local nextChunk, err, code = SqlQueryRowsExtDbCursor(
  "warehouse",
  "select sku, qty from stock where updated_at >= ? and warehouse_id = ?",
  "2026-01-01", 3
)
if code == 0 then
  local chunk, e, c = nextChunk()
  print(c, e, chunk and #chunk or 0)
end
