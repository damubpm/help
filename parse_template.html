ParseTemplate в Lua

Интерактивная шпаргалка по формированию текста, HTML, документов и динамических фрагментов из Lua-скриптов. Внутри — точная схема вызова, коды результата, доступные функции шаблона и 70 готовых примеров.

Сигнатура

result, errText, errNum = ParseTemplate(templateText, dataTable, userIdString)
АргументЧто передаватьПример
templateTextСтрока с шаблоном {{...}}"Привет, {{.name}}"
dataTableLua-таблица с данными{ name = "Ельдар" }
userIdStringСтрока, содержащая целое числоtostring(userId)
Рекомендуемый вызов: всегда приводите userId через tostring() и проверяйте errNum перед использованием результата.

Минимум

local result, errText, errNum = ParseTemplate(
    "Привет, {{.name}}!",
    { name = "Ельдар" },
    tostring(userId)
)

Шаблонный синтаксис

{{.name}} — поле; {{if ...}} — условие; {{range .items}} — перебор; функции вызываются внутри {{...}}, например {{formatNumber .amount}}.

Если поле отсутствует, обычная подстановка может дать <no value>. Для необязательных значений лучше заранее готовить данные или использовать isnil/ifnil там, где это подходит.

Важные нюансы

Стоит помнить в production-скриптах

userId — строка

Внешний вызов сначала ожидает строку, а затем преобразует ее в целое число. Используйте tostring(userId).

formatNumber

Реализация ожидает строковое значение. Наиболее безопасно хранить/передавать сумму как строку: "1250000.50".

isnil ≠ ifnil

isnil считает пустыми также "" и "<nil>", а ifnil делает fallback только для настоящего nil.

gt

Оба значения преобразуются к числу. Для предсказуемости передавайте числовые строки без валютных символов и лишних пробелов.

lua / lua2…lua5

Скрипты берутся из template_funcs по полю code. lua использует argv1…, а lua2…lua5 — param1…param5. Скрипт должен вернуть значение.

Вложенный шаблон

parseTemplate повторно обрабатывает строку-шаблон с отдельным объектом данных и тем же userId. Это удобно для переиспользуемых карточек, строк таблиц и блоков документов.

EntityValueBy*

В текущем модуле видно, что каждая из этих функций принимает три аргумента, но семантика аргументов реализована в других функциях. Поэтому примеры в справочнике показывают форму вызова, а не гарантируют конкретный порядок «entity/id/attribute» для каждой сборки.

QR-код

QRCodeBase64 value level size: уровни 0/1/2/3 соответствуют Low/Medium/High/Highest; размер 0 считается ошибочным и вернет пустой результат.

Шаблон безопасной обработки

local result, errText, errNum = ParseTemplate(template, data, tostring(userId))
if errNum ~= 0 then
    return nil, errText, errNum
end
return result, "", 0
