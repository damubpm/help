DamuBPM TigerBeetle Lua API

Справочник функций модуля, доступных из Lua.

local pkg = require("pkg/tigerbeetle")
TigerBeetle ID передаются как HEX-строки. Суммы и балансы передаются и возвращаются как десятичные строки, чтобы не терять точность 128-битных значений в Lua.
Ничего не найдено.

ID

#

Генерирует новый уникальный 128-битный идентификатор TigerBeetle. Возвращается строкой, чтобы не терять точность в Lua.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
Нет входных параметров.

Результирующие параметры

РезультатТипОписание
idstringНовый TigerBeetle ID в строковом HEX-представлении.
errstringПустая строка "" при успехе.
codeinteger0 при успехе.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local id, err, code = pkg.ID()

print("id =", id)
print("err =", err)
print("code =", code)

-- Пример результата:
-- id = 019d0f2c43f600000000000000000001
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local accountId, err, code = pkg.ID()

if code ~= 0 then
    print("Ошибка:", err)
    return
end

print("Новый accountId:", accountId)

-- Пример:
-- Новый accountId: 019d0f2c43f600000000000000000002
Пример 3
local pkg = require("pkg/tigerbeetle")

local accountId, err1, code1 = pkg.ID()
local transferId, err2, code2 = pkg.ID()

print("accountId =", accountId, "err =", err1, "code =", code1)
print("transferId =", transferId, "err =", err2, "code =", code2)

-- Пример:
-- accountId = 019d...001 err =  code = 0
-- transferId = 019d...002 err =  code = 0

Ping

#

Проверяет, может ли модуль инициализировать клиент TigerBeetle. Это проверка доступности клиента/конфигурации, а не полноценная бизнес-операция.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
Нет входных параметров.

Результирующие параметры

РезультатТипОписание
okbooleantrue, если клиент TigerBeetle успешно получен.
errstringПустая строка "" при успехе, иначе текст ошибки.
codeinteger0 при успехе, 100 при ошибке клиента.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local ok, err, code = pkg.Ping()

print("ok =", ok)
print("err =", err)
print("code =", code)

-- Пример результата:
-- ok = true
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local ok, err, code = pkg.Ping()

if not ok then
    print("TigerBeetle недоступен:", err, "code =", code)
    return
end

print("TigerBeetle клиент готов")

-- Пример:
-- TigerBeetle клиент готов

CreateAccount

#

Создаёт один счёт TigerBeetle с минимальным набором параметров: ID, ledger и code. Пользовательские поля и flags устанавливаются в 0.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
idstringTigerBeetle Account ID в HEX-строке. Обычно получается через pkg.ID().
ledgerintegerНомер ledger. Должен быть положительным uint32 и совпадать с ledger переводов.
codeintegerКод типа счёта, uint16.

Результирующие параметры

РезультатТипОписание
resulttable|nilТаблица {id, status, timestamp}. nil при ошибке до выполнения запроса.
errstringПустая строка при успехе; при бизнес-ошибке содержит status, например AccountExists.
codeinteger0 при успехе; 101 при бизнес-ошибке TigerBeetle; другие коды — ошибка параметров/клиента.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local accountId, err, code = pkg.ID()
print("ID:", accountId, err, code)

local result, err, code = pkg.CreateAccount(
    accountId,
    1,
    100
)

print("result.id =", result and result.id)
print("result.status =", result and result.status)
print("result.timestamp =", result and result.timestamp)
print("err =", err)
print("code =", code)

-- Пример результата:
-- result.id = 019d0f...
-- result.status = AccountCreated
-- result.timestamp = 1787923456789012345
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local id = "019d0f2c43f600000000000000000010"

local result, err, code = pkg.CreateAccount(id, 10, 718)

if code ~= 0 then
    print("Не удалось создать счет")
    print("status/error =", err)
    print("code =", code)
    return
end

print("Счет создан:", result.id)
print("Статус:", result.status)

-- Пример:
-- Счет создан: 019d0f2c43f600000000000000000010
-- Статус: AccountCreated
Пример 3
local pkg = require("pkg/tigerbeetle")

local id, _, _ = pkg.ID()

local first, err1, code1 = pkg.CreateAccount(id, 1, 100)
print("Первый вызов:", first and first.status, err1, code1)

local second, err2, code2 = pkg.CreateAccount(id, 1, 100)
print("Повторный вызов:", second and second.status, err2, code2)

-- Возможный результат:
-- Первый вызов: AccountCreated  0
-- Повторный вызов: AccountExists AccountExists 101

CreateAccountEx

#

Расширенное создание счёта TigerBeetle. Позволяет задать flags и пользовательские поля user_data_128, user_data_64 и user_data_32.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
idstringTigerBeetle Account ID, HEX-строка.
ledgerintegerLedger счёта, uint32.
codeintegerКод счёта, uint16.
flagsintegerБитовая маска AccountFlags. Удобно получать через pkg.AccountFlags(...).
userData128string128-битное пользовательское поле в HEX. Для нуля можно передать "0".
userData64string64-битное пользовательское поле в десятичной строке, например "12345".
userData32integer32-битное пользовательское поле.

Результирующие параметры

РезультатТипОписание
resulttable|nilТаблица {id, status, timestamp}.
errstringПустая строка при успехе или текст ошибки/status.
codeinteger0 при успехе.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local id, _, _ = pkg.ID()

local flags = pkg.AccountFlags(
    0, -- linked
    1, -- debits must not exceed credits
    0, -- credits must not exceed debits
    1  -- history
)

print("flags =", flags)

local result, err, code = pkg.CreateAccountEx(
    id,
    1,
    100,
    flags,
    "0",
    "123456",
    10
)

print("id =", result and result.id)
print("status =", result and result.status)
print("timestamp =", result and result.timestamp)
print("err =", err)
print("code =", code)

-- Пример:
-- flags = 10
-- status = AccountCreated
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local id, _, _ = pkg.ID()

local result, err, code = pkg.CreateAccountEx(
    id,
    5,
    200,
    0,
    "abc123",
    "987654321",
    42
)

if code ~= 0 then
    print("Ошибка:", err, code)
    return
end

print("Создан счет:", result.id)
print("status:", result.status)

-- userData128 = abc123
-- userData64 = 987654321
-- userData32 = 42

LookupAccount

#

Получает один счёт TigerBeetle по его ID. Возвращает текущие posted/pending дебеты и кредиты, пользовательские поля, ledger, code, flags и timestamp.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
idstringTigerBeetle Account ID в HEX-строке.

Результирующие параметры

РезультатТипОписание
accounttable|nilТаблица с данными счёта или nil, если не найден.
errstringПустая строка при успехе; "account not found" если счёт отсутствует.
codeinteger0 при успехе, 404 если счёт не найден.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local accountId = "019d0f2c43f600000000000000000010"

local account, err, code = pkg.LookupAccount(accountId)

print("account.id =", account and account.id)
print("ledger =", account and account.ledger)
print("code =", account and account.code)
print("debits_posted =", account and account.debits_posted)
print("credits_posted =", account and account.credits_posted)
print("err =", err)
print("return code =", code)

-- Пример:
-- ledger = 1
-- code = 100
-- debits_posted = 25
-- credits_posted = 100
-- err =
-- return code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local account, err, code = pkg.LookupAccount(
    "ffffffffffffffffffffffffffffffff"
)

if code == 404 then
    print("Счет не найден")
    print("err =", err)
    return
end

print("Счет:", account.id)

-- Пример:
-- Счет не найден
-- err = account not found
Пример 3
local pkg = require("pkg/tigerbeetle")

local account, err, code = pkg.LookupAccount("019d0f2c43f600000000000000000010")

if code ~= 0 then
    print(err, code)
    return
end

print("ID:", account.id)
print("Pending debit:", account.debits_pending)
print("Posted debit:", account.debits_posted)
print("Pending credit:", account.credits_pending)
print("Posted credit:", account.credits_posted)
print("History flag:", account.flag_history)

-- Все суммы возвращаются строками.

CreateTransfer

#

Создаёт обычный posted-перевод между двумя счетами TigerBeetle. Сумма передаётся десятичной строкой.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
idstringУникальный ID перевода, HEX-строка.
debitAccountIdstringID дебетового счёта.
creditAccountIdstringID кредитового счёта.
amountstringСумма в десятичной строке, например "25" или "1000000".
ledgerintegerLedger перевода. Должен совпадать с ledger обоих счетов.
codeintegerКод типа перевода, uint16.

Результирующие параметры

РезультатТипОписание
resulttable|nilТаблица {id, status, timestamp}.
errstringПустая строка при успехе или TigerBeetle status при бизнес-ошибке.
codeinteger0 при успехе.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local transferId, _, _ = pkg.ID()

local result, err, code = pkg.CreateTransfer(
    transferId,
    "019d0000000000000000000000000001",
    "019d0000000000000000000000000002",
    "25",
    1,
    200
)

print("transfer id =", result and result.id)
print("status =", result and result.status)
print("timestamp =", result and result.timestamp)
print("err =", err)
print("code =", code)

-- Пример:
-- status = TransferCreated
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local transferId, _, _ = pkg.ID()

local result, err, code = pkg.CreateTransfer(
    transferId,
    debitAccountId,
    creditAccountId,
    "150000",
    1,
    10
)

if code ~= 0 then
    print("Перевод отклонен:", err)
    print("code =", code)
    return
end

print("Перевод проведен:", result.id)

-- Пример:
-- Перевод проведен: 019d...
Пример 3
local pkg = require("pkg/tigerbeetle")

local id, _, _ = pkg.ID()

local result, err, code = pkg.CreateTransfer(
    id,
    debitAccountId,
    creditAccountId,
    "999999999999999999999",
    1,
    200
)

print("result =", result and result.status)
print("err =", err)
print("code =", code)

-- При ограничении счета возможен, например:
-- result = ExceedsCredits
-- err = ExceedsCredits
-- code = 101

CreateTransferEx

#

Расширенное создание перевода. Поддерживает pending/post/void flags, PendingID, timeout и пользовательские поля.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
idstringID нового перевода, HEX.
debitAccountIdstringID дебетового счёта.
creditAccountIdstringID кредитового счёта.
amountstringСумма в десятичной строке.
ledgerintegerLedger.
codeintegerКод перевода.
flagsintegerБитовая маска TransferFlags.
pendingIdstringID pending-перевода для post/void. Для обычного/pending перевода можно "0".
timeoutintegerTimeout pending-перевода в секундах. 0 — без timeout.
userData128stringПользовательские 128 бит HEX, либо "0".
userData64stringПользовательские 64 бита в десятичной строке.
userData32integerПользовательские 32 бита.

Результирующие параметры

РезультатТипОписание
resulttable|nilТаблица {id, status, timestamp}.
errstringПустая строка при успехе или status/ошибка.
codeinteger0 при успехе.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local transferId, _, _ = pkg.ID()

local flags = pkg.TransferFlags(
    0, -- linked
    1, -- pending
    0, -- post pending
    0  -- void pending
)

local result, err, code = pkg.CreateTransferEx(
    transferId,
    debitAccountId,
    creditAccountId,
    "1000",
    1,
    300,
    flags,
    "0",
    3600,
    "0",
    "12345",
    10
)

print("status =", result and result.status)
print("id =", result and result.id)
print("err =", err)
print("code =", code)

-- status = TransferCreated
-- err =
-- code = 0

local pkg = require("pkg/tigerbeetle")

-- Допустим pendingTransferId был создан ранее.
local postTransferId, _, _ = pkg.ID()

local postFlags = pkg.TransferFlags(

print("post status =", result and result.status)
print("err =", err)
print("code =", code)

-- Успех:
-- post status = TransferCreated
-- err =
-- code = 0
Пример 3
local pkg = require("pkg/tigerbeetle")

local voidTransferId, _, _ = pkg.ID()

local voidFlags = pkg.TransferFlags(
    0,
    0,
    0,
    1 -- void pending
)

local result, err, code = pkg.CreateTransferEx(

GetBalance

#

Возвращает текущие pending/posted обороты счёта и вычисляет удобное поле balance = credits_posted - debits_posted.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
accountIdstringИзвестный TigerBeetle Account ID в HEX-строке.

Результирующие параметры

РезультатТипОписание
balancetable|nilТаблица {id, debits_pending, debits_posted, credits_pending, credits_posted, balance}.
errstringПустая строка при успехе.
codeinteger0 при успехе, 404 если счёт не найден.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local balance, err, code = pkg.GetBalance(
    "019d0f2c43f600000000000000000010"
)

print("id =", balance and balance.id)
print("debits_pending =", balance and balance.debits_pending)
print("debits_posted =", balance and balance.debits_posted)
print("credits_pending =", balance and balance.credits_pending)
print("credits_posted =", balance and balance.credits_posted)
print("balance =", balance and balance.balance)
print("err =", err)
print("code =", code)

-- Пример:
-- debits_posted = 25
-- credits_posted = 100
-- balance = 75
-- err =
-- code = 0
Пример 2
local pkg = require("pkg/tigerbeetle")

local accountId = "019d0f2c43f600000000000000000010"

local balance, err, code = pkg.GetBalance(accountId)

if code == 404 then
    print("Счет не существует")
    return
end

if code ~= 0 then
    print("Ошибка:", err)
    return
end

print("Текущий остаток:", balance.balance)

-- Пример:
-- Текущий остаток: 7500
Пример 3
local pkg = require("pkg/tigerbeetle")

local balance, err, code = pkg.GetBalance(accountId)

if code == 0 then
    local posted = balance.balance
    local pendingDebit = balance.debits_pending
    local pendingCredit = balance.credits_pending

    print("posted balance =", posted)
    print("pending debit =", pendingDebit)
    print("pending credit =", pendingCredit)
end

-- Все значения сумм являются строками.

AccountFlags

#

Формирует числовую битовую маску флагов счёта TigerBeetle. Удобно использовать результат в CreateAccountEx.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
linkedinteger0/1. Связывает операцию с последующей в batch.
debitsMustNotExceedCreditsinteger0/1. Запрещает дебету превышать кредит.
creditsMustNotExceedDebitsinteger0/1. Запрещает кредиту превышать дебет.
historyinteger0/1. Включает историю балансов/операций счёта.

Результирующие параметры

РезультатТипОписание
flagsintegerГотовая битовая маска AccountFlags.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local flags = pkg.AccountFlags(
    0,
    1,
    0,
    1
)

print("flags =", flags)

-- Пример:
-- flags = 10
Пример 2
local pkg = require("pkg/tigerbeetle")

local flags = pkg.AccountFlags(
    0, -- linked
    0, -- debit limit off
    1, -- credit must not exceed debit
    1  -- history on
)

local id, _, _ = pkg.ID()

local result, err, code = pkg.CreateAccountEx(
    id,
    1,
    100,
    flags,
    "0",
    "0",
    0
)

print("flags =", flags)
print("status =", result and result.status)
print("err =", err)
print("code =", code)

TransferFlags

#

Формирует числовую битовую маску флагов перевода TigerBeetle. Используется для linked, pending, post pending и void pending операций.

Инициализация

local pkg = require("pkg/tigerbeetle")

Входящие параметры

ПараметрТипОписание
linkedinteger0/1. Linked transfer.
pendinginteger0/1. Создать pending transfer.
postPendingTransferinteger0/1. Подтвердить существующий pending transfer.
voidPendingTransferinteger0/1. Отменить существующий pending transfer.

Результирующие параметры

РезультатТипОписание
flagsintegerГотовая битовая маска TransferFlags.

Примеры

Пример 1
local pkg = require("pkg/tigerbeetle")

local flags = pkg.TransferFlags(
    0,
    1,
    0,
    0
)

print("pending flags =", flags)

-- Результат — целое число, которое передается в CreateTransferEx.
Пример 2
local pkg = require("pkg/tigerbeetle")

local postFlags = pkg.TransferFlags(
    0,
    0,
    1,
    0
)

local voidFlags = pkg.TransferFlags(
    0,
    0,
    0,
    1
)
